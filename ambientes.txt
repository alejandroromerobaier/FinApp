🌿 Flujo de Trabajo en Git
Rama dev (Desarrollo y QA):
Actualmente activa. Todos los nuevos desarrollos y pruebas se hacen en esta rama.
Se sube a GitHub con git push origin dev.
Rama main (Producción):
Se utiliza para almacenar únicamente el código estable desplegado en Producción.
Proceso de trabajo recomendado:
Realizamos cambios en la rama dev.
Ejecutamos npm run deploy:qa y probamos en la URL de QA.
Al confirmar que todo está OK, fusionamos dev en main y ejecutamos npm run deploy:prod.
